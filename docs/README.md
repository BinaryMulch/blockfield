# Blockfield docs

A browser-based cooperative survival horror game for family play. Run the same Node.js server on a Mac or Linux VM; players join from their browsers.

- [Current features and controls](features.md)
- [Setup, updates, saves, and Linux startup](setup.md)
- [Update the existing Linux VM](setup.md#update-the-linux-vm)
- [Deferred player identity and inventory recovery proposal](player-identity.md)

To update a running server, stop it, pull the changes, install dependencies, build, start it again, and refresh the game tabs. There is one **Horror** mode; new worlds begin near a repairable modern outpost with shared storage, reinforced construction, renewable salvage and trees, ward upkeep, and 32×32 textures, and the server listens on **port 6200**.

For more detail, see the [project README](../README.md) or the [advanced deployment guide](../deploy/LINUX.md).
